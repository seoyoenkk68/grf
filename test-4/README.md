# 3시안 2버전

기존 hero-test와 독립된 히어로 디자인 제안. 원본 테스트와 공통 프리뷰·토큰은 수정하지 않음.

실행 중인 로컬 서버에서 http://127.0.0.1:4173/test-4/ 접속.

아트 디렉션: 아이보리 헤더와 하단 카피, 풍경 안의 정제된 세리프 제목, 골드 이탤릭으로 마무리한 하나의 에디토리얼 장면. 기존 hero-1.png 원본과 동일 카피 사용. 별도 로고 원본은 없어 HTML 워드마크 표본으로 표시. 메뉴와 입사지원은 시각 표본으로 이동 기능 없음.

## 스타일 관리

- `style.css`: Forum 웹폰트와 `.grf-page`의 페이지 바탕색·기본 서체·작업용 색상 변수.
- `hero.css`: 히어로 레이아웃, 타이포, 캡션, 호버, 인트로 상태, 반응형과 모션 축소 규칙. 모든 선택자는 `.grf-hero` 내부에 한정.
- `script.js`: `.grf-hero` 인트로와 큰 텍스트·헤더·하단 캡션 등장 타이밍.
- `scroll.js`: 데스크톱 휠 한 번으로 섹션 전환. Explore와 로고도 같은 1400ms / cubic-bezier(.45, 0, .2, 1) 전환을 사용. 로고는 맨 위로 복귀하며 인트로를 재실행하지 않음. 모바일은 일반 스크롤, 모션 축소 설정에서는 즉시 이동.
- `support.css`: 두 번째 섹션은 전체 화면 사진과 왼쪽 오버레이 제목만 표시. 높이 100svh, 한글 제목 32–60px(모바일 29–42px).
- `support.js`: 한 번의 섹션 진입으로 제목 경계 리빌 → 700ms 유지 → 사진 마스크와 제목 동시 축소(1600ms)가 자동 진행. 추가 휠 입력 불필요. 이탈 후 재진입 시 초기화.
- `index.html`: `main` 안에 독립된 `section.grf-hero`를 배치. 다음 섹션은 이 section 뒤에 형제로 추가.

현재 시각 조정값은 최종 공통 토큰이 아닙니다. 디자인 시스템 원본·preview·hero-test는 변경하지 않습니다.

인트로가 완료되기 전에는 휠·터치·스크롤 키와 Explore 이동을 잠급니다. 인트로 완료, 모션 축소 또는 리사이즈로 인트로가 종료되면 자동 해제합니다.

헤더는 고정 레이어이며 원래 높이의 자리(Desktop 112px / Tablet 96px / Mobile 92px)를 유지해 히어로 배치를 보존합니다. 다음 섹션 상단에는 헤더와 내용이 겹치지 않도록 여백을 둡니다.

인트로 등장 이후 헤더는 스크롤 방향과 관계없이 상단에 계속 표시합니다.

네브는 hover/focus-visible에서 한글이 위로 빠지고 Forum 영문 이탤릭이 아래에서 올라옵니다(650ms). 두 언어가 같은 그리드 셀을 차지해 너비를 미리 확보하며 접근성 이름은 한글로 유지합니다. Forum 이탤릭 원본이 없어 히어로와 동일하게 브라우저 합성 기울임을 사용합니다. 모션 축소에서는 즉시 교체합니다.

## 다음 섹션 추가 규칙

1. 새 섹션에는 `.grf-about`처럼 독립된 루트 클래스를 붙이고 `.grf-hero` 밖에 배치합니다.
2. 새 섹션의 CSS는 `about.css`처럼 별도 파일로 만들고 해당 루트 아래에만 적용합니다.
3. `h1`, `p`, `button`, `.header` 같은 범위 없는 선택자를 추가하지 않습니다.
4. 페이지 전체에서 공유할 값만 `style.css`에 추가하고, 배치·크기 변수는 각 섹션 루트에서 관리합니다.
5. JavaScript도 해당 섹션 내부에서 요소를 찾습니다. 스크롤 안내는 히어로 다음 section이 생기면 그곳으로 이동합니다.

Forum 영문 + Pretendard 한글, 카드 상승 → 로고 대각 리빌 → 로고 사라짐 → 이미지 확장 → 쉐이드·영문 3줄 → 헤더·하단 캡션 중첩 등장. 모션 축소 환경에서는 완성 화면을 표시합니다. 하단 버튼은 Scroll to Explore입니다.











두 번째 섹션은 별도 쉐이드 없이 이미지 opacity 1을 유지합니다. 제목은 기존 짙은 잉크색을 사용합니다.


현재 두 번째 섹션은 data-motion-preview=final로 모션을 임시 정지하고 최종 구도를 표시합니다. 인물 정렬과 리사이즈 계산은 유지하며 진입·재진입 모션은 실행하지 않습니다. 자동 시퀀스 코드는 복구용으로 보존합니다.

정지된 상세 구도에 카피 원문 도입문 2개와 지원 내용 4개를 배치했습니다. 도입문은 두 단, 지원 내용은 번호·구분선이 있는 2×2 편집형 목록입니다. 모바일은 글을 먼저 읽고 사진을 아래에 배치합니다. 최종 상태 정지는 유지하며 CTA 목적 페이지는 아직 연결하지 않았습니다.

지원 카드 적용: 위 50% 영역에 각 지원 내용에 맞춘 4개의 정밀 사진(`support-card-1-mentoring.png`, `support-card-2-wellbeing.png`, `support-card-3-sales.png`, `support-card-4-branding.png`)이 순서대로 적용되었으며, 호버 시 미세 확대 트랜지션과 포토 상단 플로팅 번호 태그(`01 / GRF` 등)가 제공됩니다. 보더는 사진 영역을 제외한 하단 캡션 영역에만 연한 소프트 베이지 라인(#dcd3c7)으로 섬세하게 적용했습니다.

현재 정렬안: 카드 기울기·높낮이 제거, 좌우 동일 gutter, Desktop 한 줄 4장과 제목·도입문을 100svh 안에 배치. 오른쪽 사진 위에 카드가 걸치는 구도 및 50:50 비율 유지. Tablet은 가로 카드 스크롤, Mobile은 섹션 높이 100svh 안에서 본문 세로·카드 가로 스크롤. 1366×768 / 1280×720 / 1024×768 / 390×844에서 카드 본문 잘림과 페이지 가로 넘침 없음 확인.

모션 복구: data-support-layout=cards로 기존 사용자 편집 레이아웃을 유지하고 data-motion-preview=live로 실행합니다. 제목 리빌 → 700ms 유지 → 마스크·제목 축소(1600ms, inset 0% → 65%) → 도입문 → 카드 리빌 시 우측 대형 배경 사진이 동일한 1600ms / cubic-bezier(.45, 0, .2, 1) 마스크 클립으로 우측 끝까지 닫혀 퇴장(inset 65% → 100%, 페이드 없음) → 카드 4장 순차 리빌(1400ms, 카드별 300ms 시차)로 아이보리 바탕 전면 노출 → 카드 완료 후 .support-copy 우상단에 '설계사 지원하기' CTA 버튼 등장(is-cta-visible). 호버 시 Forum 이탤릭 영문(Apply as Planner) 전환 및 대각 화살표 모션 적용. 이탈 시 초기화하며 모션 축소 설정에서는 최종 상태를 바로 표시합니다.
