# Golden Ribbon Family · Test 03

HTML, CSS, JavaScript prototype for the “The People, The Gold” direction.

## Run locally

With Node.js installed, run from the repository root:

```sh
node preview/serve.cjs
```

Open http://127.0.0.1:4173/test-3/.

The repository includes the active prototype, two source images, the Forum font, and a local-only static server. Pretendard loads from its CDN. Card key images are pending and their spaces are intentionally empty.

Other prototypes, planning documents, design system previews and review images are excluded. Implementation notes are in `test-3/README.md`.
